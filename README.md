# chalisegrogan.github.io

Personal portfolio site. Live at [chalisegrogan.github.io](https://chalisegrogan.github.io).

Built with HTML, CSS, and vanilla JS. Hosted on GitHub Pages.

## Local dev

```bash
git clone https://github.com/chalisegrogan/chalisegrogan.github.io.git
python -m http.server 8000
```

## Structure

```
index.html      # content
css/main.css    # styles
images/         # avatar and assets
```
